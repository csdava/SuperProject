# 邻里圈——边缘视觉AI及嵌入式赋能的智能社区综合管理平台
## 项目简介
一款软硬件结合的嵌入式智慧社区管理系统，以树莓派为核心硬件载体，融合边缘视觉AI、环境传感采集、后端服务与语音交互技术。系统可实时采集社区温湿度、气压环境数据，依托轻量化YOLO模型完成人员跌倒、区域入侵异常行为检测，搭配后台管理模块与语音播报功能，实现社区安防预警、环境监测、数据统一管控一体化应用，具备低功耗、本地化推理、稳定可靠的落地使用特性。

## 技术架构
- 硬件设备：树莓派、BME280环境传感器、门传感器、摄像头、麦克风
- 开发语言：Python、C语言
- 框架服务：Django后端框架
- 核心技术：边缘AI视觉检测、串口通信、传感器数据采集、语音API对接、软硬件联调

## 核心功能
1. 环境监测：实时采集并上传温湿度、气压等环境参数
2. 智能安防：本地端识别人员跌倒、违规闯入风险场景
3. 语音交互：支持语音播报、智能语音提示提醒
4. 数据管理：后端统一存储、查看、管理设备采集数据
5. 设备联动：多终端硬件协同工作，保障系统稳定运行
